# LMS (Learning Management System)

## 📌 Project Description
This is a MERN stack based Learning Management System developed as a team project for our college assignment. It allows users to manage courses, authentication, and reviews.

## 🧑‍💻 Tech Stack (MERN)
- MongoDB (Database)
- Express.js (Backend Framework)
- React.js (Frontend)
- Node.js (Runtime Environment)

## 🚀 Features
- User Authentication (Signup/Login)
- Course Management System
- Review & Rating Feature
- Full Stack Integration (Frontend + Backend)
